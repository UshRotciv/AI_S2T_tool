# GUI 改善計畫：打造「現代知識畫廊」 

_版本: 2.0 | 日期: 2025-08-13_

## 1. 核心理念

參考現代作品集網站的設計精髓，打造一個以內容為核心、視覺驅動的「現代知識畫廊」。目標是提供一個優雅、直觀、簡潔且引人入勝的資安知識探索體驗。

---

## 2. 核心設計原則

*   **瀑布流佈局 (Masonry Layout)**：以動態、非對齊的網格展示所有情境卡片，創造視覺上的趣味性和探索感。
*   **精緻卡片設計 (Elevated Card Design)**：卡片是視覺焦點。設計將強調簡潔、質感和清晰的資訊層次。
*   **沉浸式細節檢視 (Immersive Detail View)**：點擊卡片後，在當前頁面以浮動視窗 (Modal) 展示詳細內容，保持瀏覽的流暢性。
*   **極簡化導航 (Minimalist Navigation)**：導航和篩選功能將被簡化，使其不干擾內容瀏覽。
*   **明亮通透的配色 (Light & Airy Palette)**：採用大量留白，搭配柔和、中性的背景色，並選用單一品牌色作為點綴。

---

## 3. 改善計畫三階段

### **第一階段：建立畫廊基礎與視覺風格**

**目標：** 奠定應用的核心佈局和視覺風格。

1.  **實現瀑布流佈局**：
    *   研究並引入 `react-masonry-css` 或使用 MUI v5 自帶的 `<Masonry />` 組件。
    *   將主頁改造為瀑布流佈局，動態展示所有資安情境卡片。

2.  **重新設計情境卡片**：
    *   **卡片預覽**：在瀑布流中，卡片僅顯示核心標題、分類標籤和一個代表性的圖示或縮圖。
    *   **互動回饋**：滑鼠懸停 (Hover) 時，卡片會出現細膩的陰影提升效果，並顯示「查看詳情」的提示。
    *   **樣式**：使用 `Material-UI` 的 `<Card>` 組件，但進行深度客製化，移除多餘邊框，調整圓角和陰影。

3.  **建立明亮主題**：
    *   **配色**：設定一個以白色 (`#FFFFFF`) 或極淺灰色 (`#F8F9FA`) 為主背景的 `theme`。選擇一個專業的藍色 (`#007BFF`) 或其他合適的顏色作為主要品牌色。
    *   **字體**：選用清晰易讀的無襯線字體，如 `Inter` 或 `Manrope`。

### **第二階段：優化互動與核心功能整合**

**目標：** 提升使用者與內容互動的流暢度和體驗。

1.  **開發沉浸式細節視窗 (Modal View)**：
    *   點擊卡片時，觸發一個全螢幕或大型置中的 `Material-UI` `<Modal>` 組件。
    *   Modal 內完整顯示卡片的「情境」、「解答」和「學習重點」。
    *   實現 Modal 內的上/下一個情境導航功能，讓使用者無需關閉視窗即可連續瀏覽。
    *   當 Modal 開啟時，更新瀏覽器 URL 以支援直接連結分享。

2.  **改造 AI 聊天介面**：
    *   將 AI 聊天功能從一個獨立頁面，改為一個懸浮在右下角的**浮動操作按鈕 (Floating Action Button, FAB)**。
    *   點擊 FAB 後，平滑地展開一個簡潔的聊天視窗 (Overlay)。
    *   這樣，使用者在瀏覽畫廊的任何時候都可以快速喚出 AI 助手。

### **第三階段：完善導航與細節打磨**

**目標：** 讓應用的整體體驗更加精緻和完整。

1.  **簡化頂部導航列**：
    *   導航列只保留 Logo、一個置中的**搜尋框**和**分類篩選器**。
    *   分類篩選器將從傳統下拉選單改為更現代的「標籤膠囊 (Pill)」設計，使用者可以點擊標籤進行篩選。

2.  **添加細膩的動畫效果**：
    *   使用 `framer-motion` 為以下操作添加過渡動畫：
        *   瀑布流卡片載入時的淡入和位置移動。
        *   Modal 視窗的平滑彈出和關閉。
        *   篩選內容時的卡片重新佈局動畫。

---

## 4. 技術選型建議

- **佈局庫**: `react-masonry-css` 或 `MUI Masonry`。
- **動畫庫**: `framer-motion` (用於精緻的微交互)。
- **樣式**: 深度客製化 `Material-UI` 的 `createTheme`，並大量使用 `sx` prop 進行細節調整。
- **圖示庫**: `Material Icons` 或 `Feather Icons`，選擇風格更簡潔的圖示庫。
