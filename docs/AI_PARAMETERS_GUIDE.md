## 🤖 Ollama 模型參數

### 核心生成參數
位置：`main.py` 第 1014-1024 行

```python
chat_response = ollama.chat(
    model=selected_model,
    messages=messages,
    options={
        'temperature': 0.1,      # 創造性控制
        'num_predict': 600,      # 最大生成長度
        'top_p': 0.8,           # 核採樣
        'top_k': 30             # 候選詞限制
    }
)
```

### 參數詳解

| 參數 | 當前值 | 作用 | 調整影響 |
|------|--------|------|----------|
| `temperature` | 0.1 | 控制回答的隨機性和創造性 | 越低越一致，越高越有創意 |
| `num_predict` | 600 | 限制生成的最大 token 數量 | 直接影響回答長度上限 |
| `top_p` | 0.8 | 核採樣，控制詞彙選擇範圍 | 影響回答的多樣性 |
| `top_k` | 30 | 限制每步選擇的候選詞數量 | 影響回答的一致性 |

### 歷史調整記錄
- **原始設定**：`num_predict: 300` → 導致回答被截斷
- **第一次調整**：`num_predict: 500` + `stop` 參數 → 回答過短
- **最終設定**：`num_predict: 600`，移除 `stop` 參數 → 達到理想平衡

## ✅ 回答完整性控制

### 完整性檢查函數
位置：`main.py` 第 350-417 行 `ensure_complete_response()` 函數

#### 關鍵參數

| 設定 | 值 | 作用 |
|------|-----|------|
| 完整結尾標點 | `['。', '！', '？', '：', '；', '.', '!', '?', ':', ';']` | 判斷句子是否完整 |
| 截斷門檻 | 50% | 只有在完整句子位置超過文本50%時才截斷 |
| 不完整模式移除 | `'，、,'` | 移除明顯的不完整結尾 |

#### 處理邏輯
1. **完整性檢查**：檢查是否以完整標點結束
2. **截斷檢測**：識別明顯的不完整結尾
3. **智能修正**：在保留內容和完整性間平衡

## ⚙️ 參數調優建議

## 🔧 故障排除

### 常見問題與解決方案

#### 1. 回答被截斷
**症狀**：句子說到一半就停止  
**原因**：`num_predict` 太小  
**解決**：增加 `num_predict` 值

#### 2. 回答太短
**症狀**：回答內容不夠豐富  
**原因**：`stop` 參數過早停止或完整性檢查過嚴  
**解決**：移除 `stop` 參數，調整完整性檢查門檻

#### 3. 回答不一致
**症狀**：同樣問題得到不同答案  
**原因**：`temperature` 太高  
**解決**：降低 `temperature` 到 0.1 以下

#### 4. 檢索結果不相關
**症狀**：回答內容與問題不符  
**原因**：`distance_threshold` 太寬鬆  
**解決**：降低 `distance_threshold` 值
