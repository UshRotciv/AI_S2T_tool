## ⚠️ 潛在問題與風險建議

| 問題 | 狀況 | 建議 |
|------|------|------|
| ✅ 資料儲存不持久 | `scenarios.json` 的變更只存在記憶體 | 使用 `fs.writeFileSync()` 將變更寫回檔案 |
| ⚠️ 缺乏錯誤處理 | AI 掛掉時前端或中層無處理 | try-catch 包裝 fetch，提供 fallback |
| ⚠️ 無登入驗證 | `/admin` 介面無保護 | 加入 `/login` API + localStorage token |
| ⚠️ 無備份機制 | 向量資料只有 `chroma.sqlite3` 本地檔 | 建議每日 dump 出 JSON 或 CSV 備份 |
| ❌ 無測試 | 僅有 CRA 預設樣板 | 可加入簡單 API 測試腳本或 E2E 測試 |

## 📈 系統功能一覽

### 前端 Client（React + TypeScript）

- `/`：AI 問答介面
  - 支援中文與英文切換
  - 顯示分類情境卡片
  - 搜尋功能
  - 即時對話（ChatWindow）串接 AI 回答
- `/admin`：後台管理介面
  - 可新增 / 編輯 / 刪除資安情境
  - 所有變更影響 `scenarios.json`

### 中層 App Server（Node.js）

- RESTful API
  - `GET /api/scenarios`：取得全部資料
  - `POST /api/scenarios`：新增一筆
  - `PUT /api/scenarios/:id`：更新一筆
  - `DELETE /api/scenarios/:id`：刪除
  - `POST /api/ask`：轉送至 AI Service 回答

### 底層 AI Service（FastAPI）

- 向量化與搜尋
  - 使用 `mxbai-embed-large` 做 embedding
  - 存入 `chroma_db/` 向量資料庫
- 回答生成
  - 使用 `gemma:latest` 模型
  - 基於「最相近三筆情境」進行 RAG 問答生成

## 🧩 推薦優化項目（可立即執行）

### 1. 啟用資料儲存功能
```ts
fs.writeFileSync('scenarios.json', JSON.stringify({ data: scenarios }, null, 2));
````

### 2. API 加入錯誤容錯

```ts
try {
  const res = await fetch("http://localhost:8000/api/ask", { ... });
  const json = await res.json();
  return json;
} catch (err) {
  console.error(err);
  return { error: "AI 無回應，請稍後再試。" };
}
```

### 3. 加入登入驗證（簡易版）

* 新增 `/login` 路由回傳 token
* 前端 `localStorage.setItem('adminToken')`
* 所有 PUT/POST/DELETE API 加上 token 驗證 middleware
