5. **輸入檢查＆保底邏輯集中化**

* 目的：避免 `KeyError` 或空結果時分支過多。
* 作法：抽一個 helper 檢查 `results` 是否為空；你在下半段已做一次判斷，但建議統一。

```python
def empty_results(r):
    return (not r) or (not r.get('documents')) or (not r['documents']) or (not r['documents'][0])

# 查詢完、re-rank 後立刻：
if empty_results(results):
    return {"answer":"很抱歉，我無法從現有的資料中找到與您問題相關的答案。","sources":[],"session_id":session_id}
```

（放在 /api/ask LLM 前。）

# 可修（清潔度/維運）

* **移除未用 import／函式**：`Depends`、`ingest`（現在沒用）、`handle_remove_readonly`（未呼叫）等；保持檔案乾淨。

* **距離分數解讀**：你用 `cosine`，**距離越小越像**；在 debug log / UI 顯示別誤標成分數越大越好。
